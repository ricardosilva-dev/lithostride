# LITHOSTRIDE

### The Living Colossus

Sandbox survival 2D em que o jogador vive sobre um colosso mineral gigantesco, cujo corpo é o próprio mundo, e que caminha continuamente por um mundo exterior ainda maior.

## Status

Primeiro protótipo jogável, na Unity 6000.6.2f1: menu principal, movimento do personagem, estados de caminhada do colosso, parallax, tremores e reação do ambiente aos passos. Abrir `Assets/Scenes/MainMenu/MainMenu.unity` e apertar Play — ver [Como rodar o protótipo](Documentation/Technical/SETUP_PROTOTIPO.md).

## Stack

Unity 6 LTS · C# · URP 2D · Input System · Tilemap · Cinemachine · TextMeshPro

## Plataforma

Windows, single-player, offline.
